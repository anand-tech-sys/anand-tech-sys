### 🔭 Featured Projects

**[🎙️ AI-Powered Interview Preparation Platform](https://github.com/anand-tech-sys/AI-JOB-PREP-APPLICATION)**
Full-stack AI interview app (React, Node.js, Express) with real-time, context-aware Q&A using OpenAI + LangChain + LangGraph. Features contextual memory (Mem0 + Qdrant), voice interaction (AWS TTS + Web Speech API), and an async pipeline (BullMQ + Redis) with resume/JD parsing to auto-generate tailored questions.

**[🛡️ Azure Multimodal Compliance Orchestration Engine](https://github.com/anand-tech-sys/brand-guardian-ai)**
Production-style Multimodal LLMOps app that evaluates YouTube ads against regulatory compliance guidelines. LangGraph agentic workflow integrating video ingestion, OCR, transcript extraction, RAG, and GPT-4o-based analysis, with hybrid vector search via Azure AI Search and full observability via LangSmith + Azure Application Insights.

**[🥔 Potato Disease Classification System](https://github.com/anand-tech-sys/potato-disease-classification)**
CNN-based image classifier detecting 3 potato leaf disease categories with 96%+ validation accuracy on 2,152 labeled images. FastAPI backend containerized with Docker, deployed via TensorFlow Serving on GCP, with a React Native Android app for real-time inference.
